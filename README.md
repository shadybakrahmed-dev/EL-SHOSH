# Shady Bakr — Personal Portfolio

A responsive personal portfolio website built with **HTML5**, **CSS3**, and **Bootstrap 5.3**.

## Project files

- `index.html` — page structure and content
- `style.css` — custom colors, layout, cards, and responsive styles
- `profile.jpg` — profile photo (initials "SB" are shown if the image is missing)

## Run locally

1. Download or extract the project folder (keep all files together).
2. Open `index.html` in a modern browser.
3. An internet connection is needed to load Bootstrap from the CDN.

## Publish on GitHub

1. Create a new repository, for example `shady-bakr-portfolio`.
2. Upload `index.html`, `style.css`, `profile.jpg`, and `README.md` to the repository root.
3. Commit the files.
4. To publish the site, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. The site will be available at `https://YOUR-USERNAME.github.io/shady-bakr-portfolio/`.
